# Telegram Leads Bot

Telegram-бот для автоматического сбора клиентских заявок небольшой компании услуг.

## Возможности

- выбор услуги;
- ввод своей услуги через пункт «Другое»;
- сбор имени;
- сбор телефона кнопкой Telegram или текстом;
- сбор комментария;
- подтверждение заявки перед отправкой;
- повторное заполнение с очисткой старых данных;
- отправка готовой заявки администратору;
- команды `/start` и `/cancel` работают во время заполнения;
- отдельное FSM-состояние для каждого пользователя.

## Стек

- Python 3.11+
- aiogram 3
- python-dotenv
- FSM / MemoryStorage

## Установка

Рекомендуется создать виртуальное окружение.

### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Windows

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка

Перед запуском создайте `.env` в корне проекта. Можно скопировать `.env.example`:

```text
BOT_TOKEN=your_bot_token
ADMIN_ID=your_admin_id
```

- `BOT_TOKEN` — токен Telegram-бота от BotFather.
- `ADMIN_ID` — числовой Telegram ID администратора, которому бот отправляет заявки.

Настоящий `.env` не нужно добавлять в Git.

## Запуск

```bash
python bot.py
```

Если на macOS/Linux команда `python` указывает на старую версию Python, используйте:

```bash
python3 bot.py
```

## Сценарий

1. Пользователь отправляет `/start`.
2. Нажимает «Оставить заявку».
3. Выбирает услугу или вводит свою.
4. Вводит имя.
5. Отправляет телефон контактом или текстом.
6. Добавляет комментарий.
7. Проверяет заявку.
8. Нажимает «✅ Отправить».
9. Администратор получает заявку с данными клиента, username и Telegram ID.

## Команды

- `/start` — очищает текущую заявку и начинает заново.
- `/cancel` — отменяет заполнение и очищает данные.

## Важно

FSM хранится в памяти процесса. После перезапуска бота незавершённые заявки исчезнут — для первой локальной версии это ожидаемое поведение.

- база данных;
- Google Sheets;
- CRM;
- Docker;
- VPS;
- оплата.
